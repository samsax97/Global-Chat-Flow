GLOBAL CHAT FLOW - ANDROID STARTER

Package name: com.globalchatflow.app
Firebase project: global-chat-flow

IMPORTANT:
1. Register an Android app in Firebase using package name:
   com.globalchatflow.app
2. Download google-services.json from Firebase.
3. Put google-services.json inside the app/ folder.
4. Then build the project.

Do not delete this project folder.
